# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Do not publish exploit details, credentials, recovery keys, or exported audit data in a public issue. Use the repository's private vulnerability-reporting or Security Advisory feature when available. Include the affected version, reproduction steps, impact, and a minimal sanitized example.

This project audits and can optionally modify security-sensitive Windows settings. Test suspected issues in a disposable environment and do not attach generated `Reports` or `Backups` unless they have been carefully sanitized.
